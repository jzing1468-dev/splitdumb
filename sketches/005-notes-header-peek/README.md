# 005 — Notes: Header Peek Strip

**Stance:** notes live in a strip docked under the group title. Collapsed it shows a
one-line preview of pinned notes + a count; clicking expands the full note board
in place, pushing the page down. Nothing overlays the content — expansion is inline.

- Most "fridge door" of the three: always visible, zero clicks to see the preview.
- Expansion animates open; collapses back to the same single line.
- Works identically on mobile and desktop.
- Tradeoff: when expanded it occupies vertical space in the expense page (scrolls
  away naturally, but it is visually "inside" the expense artifact more than the
  other two).
