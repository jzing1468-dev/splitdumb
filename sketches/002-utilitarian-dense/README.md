# Variant: Utilitarian Dense

## Design stance
A tool, not a toy — Linear/Spreadsheet energy. Information density first: balances as a sortable table, expenses as tight rows with hover actions, a filter bar, keyboard affordances.

## Key choices
- Layout: desktop = left nav rail + full-width balance table + list; mobile = table collapses to who/balance/status and bottom nav
- Typography: 13px base Inter, tabular numbers everywhere, 11px uppercase labels
- Color: cool gray zebra-stripes, black accent buttons, color reserved strictly for money (green/red)
- Interaction: live filter input, hover-revealed Edit/Delete, expandable split rows, ⌘K hint

## Trade-offs
- Strong at: power users, many members/expenses, desktop-first workflows, glanceability
- Weak at: cold/clinical for a friends-and-family app; mobile is a compromise (dense tables never are)

## Best for
Groups like Camping august (7 people, weeks of activity) treated as lightweight accounting rather than social splitting.
