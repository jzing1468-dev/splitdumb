# Variant: Ledger Dark

## Design stance
Make it feel like money — a dark fintech "ledger". Monospace numerals, a hero balance card with settlement progress, emerald/coral strictly for owed/owing.

## Key choices
- Layout: mobile = hero card + activity ledger + settle-up list, bottom tabs, centered add pill; desktop = sticky 380px hero/people column + activity feed
- Typography: SF Mono/JetBrains Mono for every amount, system sans for words
- Color: near-black #0c0e12, emerald accent (things owed TO you feel positive), gold for pending
- Interaction: tap-to-expand split detail, "Settle up →" CTA in hero, 34%-settled progress bar, pending pill

## Trade-offs
- Strong at: instant "what do I get back" answer, distinctive identity, great in low light (trips/camping), numbers read as authoritative
- Weak at: biggest departure from current app; dark-only by design (would need light variant); mono numerals feel technical

## Best for
Positioning SplitDumb as a trust-forward settlement tool — the "who owes whom" moment is the product.
